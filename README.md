## 第一大板块：方法对比训练（已完成）

### 目标

在统一的「21–24 训练 / 25 样本外测试」设定下，横向比较四类方法预测五只 AI 股**次日方向**（`dir_total`，收盘到收盘，含隔夜 + 日内）的能力，核心要求是**排除过拟合**——每个结果均报告训练/测试准确率缺口与 bootstrap 置信区间，只承认置信区间下界超越多数类基线的显著结果。

### 数据与特征

- **新闻表** `table1_news_scores.csv`：每条新闻含 FinBERT 情绪（`finbert_score`、`finbert_conf`）与 BART 五类零样本分类分数（chip / power / algorithm / regulation / earnings）。
- **价格表** `table2_price_targets.csv`：含 `dir_total` 等方向标签（次日方向，`ret_total = ret_overnight + ret_intraday`）。
- **筛选口径**：BART 逐类阈值归零（`< thr` 记 0，全零仍保留）；FinBERT `conf ≥ thr` 删行；三档阈值 0.5 / 0.6 / 0.7。
- **样本单位**：日频聚合（每股每天一行）与新闻级（每条一行）两种设置均测试。

### 四方法与结果

**① Bagging（决策树集成）与 ② SVM**

- 日级聚合与新闻级两套设置，5 票 × 3 阈值 × 2 模型 = 30 组合。
- **结果：0 / 30 显著**（无任何组合 bootstrap 95% CI 下界超基线）。
- Bagging 系统性过拟合（训练–测试缺口均值约 +0.13，训练 0.6+ / 测试回落至 0.5 附近）。
- SVM 缺口较小，但样本外准确率始终不超基线；高阈值下因样本减少退化为近随机。

**③ GLM 逻辑回归（字典分类 + FinBERT 情绪）**

- 字典（关键词）判主题类别，`finbert_score` 作为该类别下的连续自变量，每票一个 logit（五类五个 β）。
- 训练期出现 4 个 p < 0.1 的弱显著系数（MSFT-chip、MSFT-regulation、META-earnings、GOOGL-earnings），符号符合经济直觉。
- 但共检验 25 个 β，p < 0.1 的期望偶然数即约 2.5 个——与实际数量同量级；无一通过 p < 0.05 或多重比较校正。
- **样本外：0 / 5 显著**，五票测试准确率无一超基线。训练期弱显著 β 属多重检验噪声。

**④ LP 专家委员会（FinBERT + BART，Local Projections）**

- 按 (ticker × category) 建立日频情绪，Local Projections 估计 β，以训练期表现（无前视）筛选委员会成员（专家先验），加权融合。
- **结果：58.7% 样本外准确率，多数类基线 50.3%。**
- bootstrap 95% CI 下界 **50.9%** > 基线，P(boot > baseline) ≈ 98%。
- **三随机种子（42 / 323 / 111）均显著**，点估计稳定，CI 下界稳定过线。

### 关于字典对照（已剔除）

曾以「字典多标签分类」替换 BART 分类做对照，结果不显著。**该对照已从分析中剔除，不予采用**，原因：字典法仅为关键词硬匹配，无法处理语序与语境，本身不是合格的文本表征——其不显著无法反证 BART 版结果，不具诊断价值。

文本表征的精度层级为：**字典 < BART < 人工专家评估**。人工逐条标注为精度上限但资源不可行；BART 为可自动化范围内的半精确最优方案，故采用 BART 版为主结果。

### 第一大板块结论

在几乎所有方法失效的背景下，唯有采用语义级表征（BART）结合专家先验筛选的 LP 委员会取得统计显著的样本外方向可预测性（58.7%，三种子稳健）：

- 朴素全特征机器学习（Bagging / SVM / GLM）全面失效，树集成严重过拟合；
- 情绪对 AI 股次日方向的预测力若存在，则**高度稀疏、异质，且依赖语义级表征**，需专家先验剔除噪声方能显现；
- 该发现与后续 VAR / ACF / PACF（个股间传导微弱、情绪–收益无稳定时序关系）相互印证。

### 局限（两条独立说明）

1. **表征精度局限**：理想的人工专家逐条标注不可行，采用 BART 半精确替代；结论建立在半精确表征之上。
2. **时间外部效度局限**：仅 2025 一个可测样本外年份，21–24 数据量不足以支撑更早的滚动切分；58.7% 是否为结构性信号，抑或绑定 2025 年特定市场状态（NVDA 主导、H100 驱动的 AI 行情）的状态依赖信号，尚待 2026 年及以后数据检验。此问题由后续泡沫分析与敏感性测试处理，与表征精度局限相互独立。
